# Where2Swim 🌊

Mobile app που δείχνει live συνθήκες (άνεμος, κύμα, θερμοκρασία νερού) σε **202 παραλίες** της Κρήτης (28 επιμελημένες + 174 αυτόματα εντοπισμένες μέσω OpenStreetMap), ώστε ο χρήστης να βρίσκει εύκολα ποια παραλία είναι προστατευμένη/ήρεμη τη δεδομένη μέρα — με φίλτρα ανά νομό, συνθήκες και απόσταση. Οι χρήστες μπορούν επίσης να προσθέτουν δικές τους παραλίες, ορατές σε όλους.

## Stack

- [Expo](https://expo.dev) / React Native (TypeScript)
- Καιρικά δεδομένα: [Open-Meteo](https://open-meteo.com) (δωρεάν, χωρίς API key) — άνεμος, θερμοκρασία, ύψος κύματος
- Τοποθεσία: [expo-location](https://docs.expo.dev/versions/latest/sdk/location/)
- Οδική απόσταση/χρόνος: [OSRM](https://project-osrm.org) δημόσιο demo API (δωρεάν, χωρίς key — **όχι** για βαριά production χρήση, θα χρειαστεί δικό μας routing API αργότερα)
- Αναζήτηση τοποθεσίας (add-beach): [Nominatim/OpenStreetMap](https://nominatim.org) (δωρεάν, χαμηλός όγκος)
- Χάρτης: [react-native-maps](https://github.com/react-native-maps/react-native-maps)
- Κοινόχρηστη βάση δεδομένων (community beaches): [Supabase](https://supabase.com) (δωρεάν tier, Postgres)

## Ξεκίνημα

```bash
npm install
```

### Ρύθμιση Supabase (για τη λειτουργία "Πρόσθεσε παραλία")

1. Δημιούργησε δωρεάν λογαριασμό στο [supabase.com](https://supabase.com) και ένα νέο project.
2. Στο project, πήγαινε **SQL Editor → New query**, επικόλλησε το περιεχόμενο του [`supabase/schema.sql`](./supabase/schema.sql) και πάτησε Run. Αυτό δημιουργεί τον πίνακα `community_beaches` με τους κανόνες πρόσβασης.
3. Πήγαινε **Authentication → Sign In / Providers** και ενεργοποίησε **Anonymous Sign-ins**. Χρειάζεται ώστε κάθε συσκευή να έχει μια αόρατη, μόνιμη ταυτότητα (χωρίς login/κωδικό) που ξεχωρίζει "τις δικές σου εκκρεμείς παραλίες" από των άλλων.
4. Πήγαινε **Project Settings → API** και αντίγραψε το **Project URL** και το **anon public** key.
5. Αντίγραψε το `.env.example` σε `.env` και βάλε τις δικές σου τιμές:
   ```
   EXPO_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxx
   ```
6. Χωρίς αυτό το βήμα, η εφαρμογή δουλεύει κανονικά με τις built-in παραλίες — απλά η προσθήκη νέων παραλιών θα δείχνει μήνυμα ότι δεν έχει ρυθμιστεί.

### Έγκριση νέων παραλιών (moderation)

Κάθε παραλία που προσθέτει ένας χρήστης είναι **ιδιωτική** μέχρι να την εγκρίνεις: τη βλέπει μόνο η συσκευή που την έστειλε (με badge "⏳ Εκκρεμεί έγκριση"), σαν αίτημα προς εσένα. Για να την κάνεις ορατή σε όλους:

1. Supabase dashboard → **Table Editor** → πίνακας `community_beaches`
2. Βρες τη γραμμή, άλλαξε το πεδίο **status** από `pending` σε `approved`
3. Θα εμφανιστεί σε όλους τους χρήστες στο επόμενο refresh

Αν έτρεξες παλιότερα το `schema.sql` και έχεις ήδη πίνακα, τρέξε το [`supabase/migration_private_submissions.sql`](./supabase/migration_private_submissions.sql) στο SQL Editor για να τον αναβαθμίσεις (δεν χάνει δεδομένα — οι υπάρχουσες παραλίες γίνονται αυτόματα "approved").

### Εκκίνηση

```bash
npm start
```

Μετά σκάναρε το QR code με το [Expo Go](https://expo.dev/go) app στο κινητό σου (iOS/Android) για να δεις live preview χωρίς build.

## Features

- [x] Λίστα παραλιών σε όλους τους 4 νομούς της Κρήτης (Χανιά, Ρέθυμνο, Ηράκλειο, Λασίθι)
- [x] Live άνεμος/κύμα/θερμοκρασία ανά παραλία (Open-Meteo), με πρόβλεψη 5 ημερών (επιλογή "Σήμερα/Αύριο/..." χωρίς επιπλέον requests — φορτώνεται μία φορά και φιλτράρεται τοπικά)
- [x] Αυτόματη ταξινόμηση + badge "Καλύτερη επιλογή" (ανά επιλεγμένη ημέρα)
- [x] Χάρτης με έγχρωμα pins ανά συνθήκη ανέμου
- [x] Ελληνικά / English (πλήρες i18n)
- [x] Φίλτρα (πτυσσόμενα, με badge ενεργών): νομός, μόνο ήρεμες συνθήκες, απόσταση/χρόνος, αναζήτηση με όνομα
- [x] Τοποθεσία χρήστη (με άδεια) → απόσταση σε km + εκτιμώμενος χρόνος οδήγησης ανά παραλία
- [x] Pull-to-refresh
- [x] Προσθήκη παραλίας από τον χρήστη (live αναζήτηση με typo-tolerance, φιλτραρισμένη σε πραγματικές παραλίες + spatial αναζήτηση κοντινών όταν δεν βρεθεί ακριβές match, ή pin στον χάρτη) → όνομα κλειδωμένο από την πηγή, νομός & πλευρά ακτής (Β/Ν/Α/Δ) εντοπίζονται αυτόματα, έλεγχος διπλότυπων → αποθηκεύεται στο Supabase ως **ιδιωτική** (μόνο η συσκευή του χρήστη τη βλέπει) μέχρι να την εγκρίνεις χειροκίνητα
- [x] Αγαπημένες παραλίες (αστεράκι σε κάθε κάρτα, τοπική αποθήκευση στο κινητό, φίλτρο "μόνο αγαπημένες")
- [x] Η επιλογή ημέρας είναι κοινή ανάμεσα σε Λίστα και Χάρτη
- [x] Έλεγχος/moderation πριν τη δημοσίευση νέων παραλιών (ιδιωτικές μέχρι να εγκριθούν από τον διαχειριστή μέσω Table Editor)
- [x] Οθόνη λεπτομερειών παραλίας (πάτα σε μια κάρτα) — μεγάλη προεπισκόπηση χάρτη, δείκτης UV, πρόγευση 5 ημερών με μια ματιά
- [x] Κουμπί "Οδηγίες" — ανοίγει Google/Apple Maps με πλοήγηση κατευθείαν στην παραλία
- [x] Κουμπί "Κοινοποίηση" — μοιράσου μια παραλία μέσω του native share sheet
- [x] Οθόνη καλωσορίσματος στην πρώτη εκκίνηση
- [ ] Φωτογραφίες/λεπτομέρειες παραλίας (πρόσβαση, παροχές)
- [ ] Push notification όταν μια αγαπημένη παραλία γίνεται ήρεμη
- [ ] Δικό μας/παραγωγικό routing API (αντί για το δωρεάν OSRM demo)
