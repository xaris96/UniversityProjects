# Doughnut Pyplot Project

## Overview
The Doughnut Pyplot Project is designed to create interactive doughnut charts using Matplotlib's pyplot. This project provides a set of tools for data manipulation and visualization, making it easy to analyze and present data in a visually appealing format.

## Project Structure
```
doughnut-pyplot-project
├── src
│   ├── plot_doughnut.py     # Main logic for plotting the doughnut chart
│   └── utils.py             # Utility functions for data manipulation
├── notebooks
│   └── save.ipynb           # Jupyter notebook for interactive analysis
├── requirements.txt          # Project dependencies
├── pyproject.toml           # Project configuration
├── .gitignore                # Files and directories to ignore in Git
└── README.md                 # Project documentation
```

## Installation
To set up the project, clone the repository and install the required dependencies. You can do this by running:

```bash
pip install -r requirements.txt
```

## Usage
1. **Data Preparation**: Use the functions in `utils.py` to prepare your data for visualization.
2. **Plotting**: Call the functions in `plot_doughnut.py` to create doughnut charts. You can customize the appearance and behavior of the charts as needed.
3. **Interactive Analysis**: Open the `notebooks/save.ipynb` file in Jupyter Notebook to explore the data and visualize it interactively.

## Dependencies
This project requires the following Python libraries:
- Matplotlib
- Pandas

Make sure to install these libraries before running the project.
