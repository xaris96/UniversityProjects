## Notes
- The portfolio copy keeps scripts and deliverables, but sensitive credentials were replaced with placeholders where needed.
- For the Java SQL utilities, set `DB_NAME`, `DB_USER`, and `DB_PASSWORD` in the environment instead of hardcoding connection details.
- JDBC driver jars and expanded driver folders are not included; install the relevant driver locally before running the Java examples.
