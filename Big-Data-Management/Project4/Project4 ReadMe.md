# Project 4 - Real-Time Stream Processing with Azure Event Hubs & Stream Analytics

## Overview

This project implements a real-time data streaming pipeline using Microsoft Azure services.  
The scenario is based on ATM transaction events generated by a Python script and processed in real time through Azure Stream Analytics.

The pipeline follows this architecture:


Python ATM Generator → Azure Event Hub → Azure Stream Analytics Jobs → Azure Blob Storage


The Python generator continuously creates simulated ATM transactions and sends them to Azure Event Hub.  
Five Azure Stream Analytics jobs process the incoming stream using different windowing techniques and write the results as JSON files to Azure Blob Storage.

### `atm_generator.py`

This script generates simulated ATM transaction events and sends them to Azure Event Hub.

Each generated event contains:

```json
{
  "eventTime": "timestamp",
  "area": "ATM area",
  "atmId": "ATM identifier",
  "accountId": "Account identifier",
  "transactionType": "withdrawal/deposit/balance_inquiry/transfer",
  "amount": "transaction amount",
  "currency": "EUR"
}
```

The script sends events continuously at fixed intervals.

## Running the Python ATM Generator

### 1. Create and activate a virtual environment

On Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

On macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install requirements

```bash
pip install -r requirements.txt
```

### 3. Configure the generator

Before running the script, the following variables in `atm_generator.py` must be configured:

```python
HOST_NAME = "your-event-hub-namespace.servicebus.windows.net"
SHARED_ACCESS_KEY_NAME = "sender-policy"
SHARED_ACCESS_KEY = "your-primary-key"
EVENT_HUB_NAME = "atm-transactions"
```

> Important: The shared access key is not included in this repository for security reasons.

### 4. Run the generator

```bash
python atm_generator.py
```

When the script runs successfully, it prints messages like:

```text
Connection established. Sending ATM events...
Sent: {"eventTime": "...", "area": "...", "atmId": "...", ...}
```

The generator was left running while the Stream Analytics jobs were active.

## Task 1 - Transaction Volume per Area

### Description

Calculate the number of transactions and the total transaction amount per area every 1 minute.

### Window Type

Tumbling Window

### Input

```text
atmInput
```

### Output

```text
task1Output
```

### Blob Container

```text
task1-volume-area
```

### Query

```sql
SELECT
    System.Timestamp() AS windowEnd,
    area,
    COUNT(*) AS transactionCount,
    SUM(amount) AS totalAmount
INTO
    task1Output
FROM
    atmInput TIMESTAMP BY eventTime
GROUP BY
    area,
    TumblingWindow(minute, 1)
```

### Output Fields

| Field | Description |
|---|---|
| `windowEnd` | End time of the processing window |
| `area` | ATM area |
| `transactionCount` | Number of transactions in the window |
| `totalAmount` | Total transaction amount in the window |

## Task 2 - High-Value Withdrawals

### Description

Every minute, calculate how many withdrawals of €200 or more occurred in each area during the last 10 minutes.

### Window Type

Hopping Window

### Input

```text
atmInput
```

### Output

```text
task2Output
```

### Blob Container

```text
task2-high-value-withdrawals
```

### Query

```sql
SELECT
    System.Timestamp() AS windowEnd,
    area,
    COUNT(*) AS highValueWithdrawalCount,
    SUM(amount) AS totalHighValueWithdrawalAmount
INTO
    task2Output
FROM
    atmInput TIMESTAMP BY eventTime
WHERE
    transactionType = 'withdrawal'
    AND amount >= 200
GROUP BY
    area,
    HoppingWindow(minute, 10, 5)
```

### Output Fields

| Field | Description |
|---|---|
| `windowEnd` | End time of the processing window |
| `area` | ATM area |
| `highValueWithdrawalCount` | Number of high-value withdrawals |
| `totalHighValueWithdrawalAmount` | Total amount of high-value withdrawals |

## Task 3 - Burst Activity per Account

### Description

Detect accounts that perform 3 or more transactions within 30 seconds, indicating potential suspicious activity.

### Window Type

Sliding Window

### Input

```text
atmInput
```

### Output

```text
task3Output
```

### Blob Container

```text
task3-burst-accounts
```

### Query

```sql
SELECT
    System.Timestamp() AS windowEnd,
    accountId,
    COUNT(*) AS transactionCount
INTO
    task3Output
FROM
    atmInput TIMESTAMP BY eventTime
GROUP BY
    accountId,
    SlidingWindow(second, 30)
HAVING
    COUNT(*) >= 3
```

### Output Fields

| Field | Description |
|---|---|
| `windowEnd` | End time of the processing window |
| `accountId` | Account identifier |
| `transactionCount` | Number of transactions within 30 seconds |

## Task 4 - Average Withdrawal Amount per Area

### Description

Every 5 minutes, calculate the average withdrawal amount per area, considering only withdrawal transactions.

### Window Type

Tumbling Window

### Input

```text
atmInput
```

### Output

```text
task4Output
```

### Blob Container

### Query

```sql
SELECT
```

| Field | Description |
|---|---|
| `windowEnd` | End time of the processing window |
| `area` | ATM area |
| `averageWithdrawalAmount` | Average withdrawal amount |
| `withdrawalCount` | Number of withdrawal transactions |
