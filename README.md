## Included projects
*   **Algorithm-Assignments**: Συλλογή ασκήσεων από το μάθημα των αλγορίθμων.
*   **Big-Data-Management**: Project σχετικό με τη διαχείριση και επεξεργασία μεγάλου όγκου δεδομένων.
*   **Clio-Customer-Journey**: Ανάλυση δεδομένων από logs για την χαρτογράφηση της διαδρομής του πελάτη (Customer Journey).
*   **Supermarket data**: Ανάλυση δεδομένων για την τμηματοποίηση πελατών βάσει των χαρακτηριστικών ή της συμπεριφοράς τους.
*   **Insurance-Management**: Σύστημα διαχείρισης για ασφαλιστική εταιρεία, πιθανόν με χρήση βάσης δεδομένων.
*   **Java-Coursework**: Διάφορες ασκήσεις και projects από τα μαθήματα Java.
*   **JSP-Registration-Exercises**: Ασκήσεις με JavaServer Pages (JSP) για τη δημιουργία φορμών εγγραφής χρηστών.
*   **Machine-Learning**: Συλλογή ασκήσεων και projects από το μάθημα της Μηχανικής Μάθησης.
*   **Smarket**: Ανάπτυξη εφαρμογής σχετικής με αγορές (π.χ. Super Market ή Stock Market).
*   **Flask-Projects**: Συλλογή projects που χρησιμοποιούν το web framework Flask της Python.
*   **SQL-Database-Coursework**: Ασκήσεις και projects σχετικά με SQL και διαχείριση βάσεων δεδομένων.

## Notes
- Build folders, virtual environments, compiled files, local databases, archives, shortcuts, and large vendor/dependency trees are excluded.
- Raw/private data was removed where it could expose client, participant, or runtime database contents.
- Credentials were replaced with environment-variable based placeholders where needed.
- Notebook outputs were stripped so the portfolio shows the code without embedded private result tables or previews.
- Source files and deliverables are kept where they are safe to publish.
